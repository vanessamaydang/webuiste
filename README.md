# webuiste

Uebungsprojekt: einfache Website + Git/GitHub verstehen.

## Ordnerstruktur

```
webuiste/
├── index.html      # Startseite
├── css/style.css   # Styling
├── js/script.js    # Interaktion
├── images/         # Bilder
└── README.md       # diese Datei
```

## Git-Grundablauf

```bash
git status                 # was hat sich geaendert?
git add .                  # Aenderungen vormerken
git commit -m "Nachricht"  # lokal speichern
git push                   # zu GitHub hochladen
git pull                   # von GitHub holen
```
